## ⚡ Что это такое?

**Direction** — это флагманский фреймворк, разработанный для создания массивных и качественных датасетов под задачи Object Detection (YOLOv8+, PASCAL VOC, COCO).

В отличие от стандартных генераторов, которые просто рисуют коробки вокруг коллайдеров, этот движок использует алгоритм **Raycast Surface Sampling**. Он сканирует реальную геометрию объектов (включая анимированные Skinned Meshes), учитывая перекрытия, препятствия и перспективу камеры.

**Результат?** Качественные синтетические данные, используя которые можно обучить точную нейросеть.

## ✨ Ключевые возможности

### 🎯 Идеально точная аннотация (Pixel-Perfect)
*   **Raycast Occlusion Culling:** Использует алгоритм проекции облака точек. Если машина частично скрыта за стеной, рамка (Bounding Box) автоматически сжимается, охватывая только *видимую* часть (бампер/фары).
*   **Поддержка Mesh & SkinnedMesh:** Работает как с твердыми телами (`MeshFilter`), так и с анимированными персонажами (`SkinnedMeshRenderer`).
*   **Dynamic Baking:** Автоматическое запекание анимации (BakeMesh) в реальном времени для генерации точных рамок под любую позу бегущего человека.

### 🌐 Продвинутые технологии Sim2Real
*   **Domain Randomization (DR):** Полная рандомизация освещения (HDRi Skyboxes), погоды (туман/дождь), текстур материалов и цветов объектов для предотвращения переобучения.
*   **Аугментация камеры:** Автоматическая вариация FOV, наклона, поворота и крена, имитирующая небрежную установку реального регистратора.
*   **Имитация оптики:** Внедрение артефактов реальных камер: ISO-шум, размытие в движении, хроматическая аберрация и дисторсия линзы.

### 🔌 Интеграция с Python через ZeroMQ
*   **Архитектура REQ-REP / PUB-SUB:** Полная оркестрация цикла обучения с подробной документацией на сайте.
*   **Двусторонний контроль:** Unity стримит данные в Python; скрипты Python управляют симуляцией (Старт/Стоп/Сброс/Параметры) в реальном времени.
*   **Никаких файлов:** Обмен данными через высокоскоростные асинхронные TCP сокеты, без бутылочного горлышка в виде записи на диск.

## 🛠 Архитектура

### Сторона C# (Unity)
Менеджер `ZeroMqManager` обрабатывает асинхронную связь. Ядро генерации строится вокруг компонента `TrainingObject`:

```csharp
// Пример того, как движок обрабатывает анимированные меши
if (isStatic) {
    // Кэшируется один раз для максимальной производительности (Машины, Столбы)
    points = _staticParts; 
} else {
    // Динамическое запекание вершин каждый кадр для идеального облегания (Люди)
    skinnedMeshRenderer.BakeMesh(_tempMesh);
    points = ScanMesh(_tempMesh);
}
```

### Сторона Python (Оркестратор)
Скрипты запускаются внешне через `PyModule` и общаются по ZMQ.

```python
from unity_connector import UnityConnector

connector = UnityConnector(script_name="detector.py")

# Обработка команд напрямую из UI Unity
connector.on_command("SET_THRESHOLD", lambda data: update_params(data))

# Отправка событий обратно в симуляцию
connector.send_event("OBJECT_DETECTED", {"class": "car", "confidence": 0.95})
```

## 🚀 Начало работы

### Требования
1.  **Unity 2021.3+** (поддержка URP и Built-in RP).
2.  Пакет **NetMQ** (установить через NuGet for Unity).
3.  **Python 3.9+** с библиотекой `pyzmq`.

### Установка
1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/TheLemzz/Direction.git
    ```
2.  Откройте проект в Unity.
3.  Установите зависимости Python:
    ```bash
    pip install -r requirements.txt
    ```

### Как использовать

1.  **Настройка сцены:**
    *   Добавьте префаб `ZeroMqManager` на сцену.
    *   Повесьте скрипт `YOLOAnnotationGenerator` на камеру.
2.  **Разметка объектов:**
    *   Добавьте скрипт `TrainingObject.cs` на любой префаб (Машина, Человек).
    *   Включите галочку `IsStatic` для машин (Производительность).
    *   Выключите `IsStatic` для анимированных людей (Точность).
3.  **Запуск:**
    *   Нажмите Play, выберите сохранение и запустите симуляцию. Камера начнет движение, рандомизируя окружение и стримя аннотации (YOLO .txt) в вашу выходную папку.
